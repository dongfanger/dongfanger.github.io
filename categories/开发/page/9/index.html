本书作者：测试开发刚哥，文章版权归个人所有，未经授权请勿转载。 Servlet 生命周期 Servlet 的生命周期由 Servlet 容器（如 Tomcat、Jetty 等）管理，主要包括以下 5 个阶段： 加载 Servlet 类 创建 Servlet 实例 调用 init 方法 调用 service 方法 调用 destroy 方法 加载（Loading）： 当 Servlet 容器启动或第一次接收到对某个 Servlet 的请求时，它会加载 Servlet 类 这个过程只发生一次，除非 Servlet 被卸载或容器重新启动 实例化（Instantiation）： 在加载 Servlet 类之后，容器会创建一个 Servlet 实例 这个实例化过程也是一次性的，除非 Servlet 被卸载或容器重新启动 初始化（Initialization）： 容器调用 Servlet 实例的init()方法进行初始化 init()方法只被调用一次，用于执行一次性的初始化任务，如读取配置参数、初始化资源等 你可以重写init()方法以执行自定义的初始化逻辑 public void init(ServletConfig config) 请求处理（Request Handling）： 每当有请求到达时，容器会调用 Servlet 的service()方法来处理请求 service()方法根据请求的类型（如 GET、POST 等）调用相应的处理方法（如doGet()、doPost()等） public void service(ServletRequest request, ServletResponse response) 销毁（Destruction）： 当容器决定卸载 Servlet（如容器关闭或 Servlet 被重新加载）时，它会调用 Servlet 的destroy()方法 destroy()方法用于执行清理任务，如关闭资源、保存状态等 destroy()方法只被调用一次 public void destroy() ...
