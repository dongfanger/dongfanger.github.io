一文讲透 claude.ai、Claude API 与 Claude Code 到底谁是谁

2026-11-10 · 人工智能 · #Claude

很多人第一次接触 Claude 时，都会被三个长得有点像的名字绕晕：claude.ai、Claude API、Claude Code。它们到底什么关系？ 这篇文章把它们的区别讲清楚。

两个产品，一个内核#

claude.ai 和 Claude Code 是"产品"，Claude API 是"内核"。 两个产品底层都是通过 API 这条通道去连模型的。

  • Claude API：本质是模型本身。输入输出的问答。
  • Claude Code：本质是产品。模型 + 界面 + 文件读写 + 终端 + 联网 + 各种工具，全套打包。
  • claude.ai：本质是产品。模型 + 网页聊天界面。

Claude API 只干"连接模型"这一件事#

Claude API 就是那条连接模型的通道。

你的程序 ──HTTP请求──▶ Claude API ──▶ 模型
        ◀──HTTP响应──                ◀── 返回结果

Claude API 不给你界面、不给你文件系统、不给你浏览器、不给你联网、不给你装包。它就干一件事：你把文字/图片/工具定义发过去，它把模型的回答返回给你。 剩下的一切（界面、存数据、跑代码、联网）都是你自己程序的事。

它是把 Claude 集成进你产品的唯一正经方式。你能想到的几乎所有 LLM 应用：电商客服、代码审查 bot、RAG 问答、文档解析、自动化 agent，底层走的都是 Claude API。Claude Code 本身，也不过是这个 API 的一层封装。

它的用法是：写你自己的后端程序（Python / Node / Go 等），让你的程序去调用模型。这个程序跑在你自己的服务器上，就是一个普通的服务端应用，联网、装包、调用内部接口，都由你自己控制。

官方 API 里还有一个叫 code_execution 的服务端工具，可以理解为“云端临时沙箱”。模型生成代码后，由 Anthropic 的服务端执行，再把结果返回给你。 它只是可选附加功能，适合不想自己搭执行环境、只想让模型临时跑一小段代码的场景。不用它，完全不影响正常开发。

“CC 代理”#

Claude Code 本质上就是"Claude API 的一个客户端"。

“CC 代理”，指让 Claude Code 能连上模型的网络代理。国内直连 Anthropic 不通，得借道（公司代理 / 中转站）绕出去。

Token：模型的"计量单位"与计费公式#

一句话发给模型前，先被"分词"成一串 token 编号。

大致换算：

  • 英文：约 4 个字符 ≈ 1 token（Hello world ≈ 2 token）
  • 中文：约 1 个汉字 ≈ 1～2 token

计费公式：

费用 = 输入 token 数 × 输入单价 + 输出 token 数 × 输出单价
  • 输入 token：你发的每一句、系统提示、工具定义，以及全部历史对话（每轮都会重发一遍，所以越聊越贵）。
  • 输出 token：模型生成的回答，包括它的"思考过程"（thinking 也计费）。

关键：输出比输入贵得多。 以 2026 年 9 月发布的 Claude Opus 5.5 为例（单位：每 100 万 token）：

  • 输入：$4 / 1M
  • 输出：$20 / 1M（是输入的 5 倍）
  • 缓存命中：$0.20 / 1M（超便宜）

那个"缓存"是指：如果两次请求的前缀完全一致（比如固定的系统提示、没变的历史对话），相同部分按超低价算，不重复收全额。写应用时，把不变的内容放前面、把变化的放后面，省钱。

为什么 Claude Code 能随便切模型？#

因为模型只是请求里的一个参数。

Claude Code 发请求时，body 里带：
{
  "model": "claude-opus-5-5",   ← 就这一个字段
  "messages": [...],
  ...
}

模型跑在 Anthropic 的服务器上，Claude Code 只是个客户端。你把 model 字段从 A 换成 B，就是告诉服务器"这次给我上这个模型"。于是：

  • 切模型 = 改一个字符串参数。
  • 模型本体在你本地根本没有，全在云端，客户端只是"选谁来服务"。
  • 这也是为什么前面说"CC 代理"是"连模型"，你连的是云端的模型池。

小结#

  1. claude.ai / Claude Code 是产品，Claude API 是内核；产品是包装，API 是让你做产品的原材料。
  2. Token 是模型的计量单位，输入 + 输出分开算、输出更贵、前缀可缓存省钱。
  3. Claude Code 能切模型，是因为它只是个发请求的客户端，模型是云端资源，靠 model 字段来选。

把这三件事串起来看，会发现所谓"接入 Claude"其实很简单，模型在云端，API 是通道，Claude Code、claude.ai 都只是在通道上包了一层壳的客户端。
