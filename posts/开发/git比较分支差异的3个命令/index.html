Git 比较分支差异的 3 个命令

2026-01-03 · 开发 · #Git

本书作者：测试开发刚哥，文章版权归个人所有，未经授权请勿转载。

查看本地分支

git branch

查看远端分支，无论是否 checkout 到本地

git branch -r

假如想比较 dev 和 master

命令 1：比较文件

git diff dev master --stat

命令 2：比较提交日志

git log dev ^master

git log master..dev  # since..until，包含了在dev分支而不在master分支中所有的提交，若无结果，说明dev的所有提交都合到了master

这 2 种等价。

git log dev...master

dev 和 master 的所有差异，可以加–left-right 参数，指明属于哪个分支的 commit。

命令 3：列出合并到 master 的分支，master >= dev

git branch --merged master
